A local, encrypted workbench for market data: ingest, search, journal, model and share, in a terminal UI and a CLI.

Releases Install Screenshots Docs Source

Encrypted and local

A SQLCipher database under an envelope key scheme. Nothing leaves your machine unless you share it.

Ingest anything

CSV, JSON, HTTP APIs, Redis, SQLite, Postgres and standard input, as structured data.

Live searches, journals, reports

Saved questions that rerun on new data, notes beside the charts, reports exported to PDF and Docx.

Models and code spaces

Design model tables, then run math, Polars, Rust or Python over data piped through them.

Pipelines

Graphs of sources, code, views and filters ending in model tables, watched live in tiles.

Rules and schedules

If this happens, do that, or every 6 hours: exports, entries, records, certificate checks.

Organizations

Members, roles and a hosted site with your own domains and Let's Encrypt certificates.

Peer to peer

Your nodes sync end to end encrypted; share and review with connections, no server needed.

Screenshots

Every view in the TUI, rendered from the app itself by scripts/screenshots.sh.

Install

Every package ships a prebuilt mnnn binary; no Rust toolchain is needed. Downloads and SHA256SUMS are on the releases page. Full steps, uninstalling and building from source: the install guide.

Release tarball (Linux, macOS)

tar -xzf muninn-2.20.0-x86_64-unknown-linux-gnu.tar.gz
mkdir -p ~/.local/bin
install -m755 muninn-2.20.0-x86_64-unknown-linux-gnu/mnnn ~/.local/bin/mnnn

Debian / Ubuntu

sudo apt install ./muninn_2.20.0-1_amd64.deb

Fedora

sudo dnf install ./muninn-2.20.0-1.x86_64.rpm

Arch Linux

sudo pacman -U muninn-bin-2.20.0-1-x86_64.pkg.tar.zst

Homebrew (macOS, Linux)

tar -xzf muninn-2.20.0-packaging.tar.gz
brew tap-new --no-git local/muninn
cp packaging/homebrew/muninn.rb "$(brew --repository local/muninn)/Formula/"
brew install local/muninn/muninn

Windows (PowerShell)

curl.exe -LO https://github.com/WeirdBrains/muninn/releases/download/v2.20.0/muninn-2.20.0-x86_64-pc-windows-gnullvm.zip
Expand-Archive muninn-2.20.0-x86_64-pc-windows-gnullvm.zip $env:LOCALAPPDATA\Programs -Force
# then add the folder to your user PATH and open a new terminal: see muninn.weirdbrains.com/docs/install

Your data stays in ~/.muninn (or MUNINN_HOME); installing or uninstalling never touches it.
