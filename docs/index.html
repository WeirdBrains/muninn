Muninn documentation

Muninn (mnnn) ingests crypto market data from files and services, normalizes it into bars and stores them in an encrypted SQLite database. These pages are also the in-app help (? or F1 in the TUI, mnnn help <topic> on the command line).

Research

  • Live searches: saved searches that always run on current data; fork and optimize
  • Projects: live searches, results and journals together
  • Journals: Markdown or LaTeX entries with images, notes and highlights
  • Reports: sections built from records, journals, projects and authors
  • Rules: when an action happens, run searches, export, write entries or notes, feed models
  • Models: design record tables, migrate them with previews and roll back; records
  • Model design templates: export, import and share model designs; built-in templates
  • Code spaces: math, Polars, Rust or Python compiled to native plugins over your data
  • Export formats: PDF, HTML, Word, LaTeX, JSON, CSV; printing; project archives and import

Network

  • Network: the node, peers, relays, sharing and searching across peers; the Net menu
  • Users and connections: your user identity, linked nodes, trusted connections, invites
  • Linked-node sync: all of your data on all of your nodes, conflicts, bars on request
  • Key exchanges: offers, answers, short codes, verifying, revoking, backups
  • Dark shards: the master key split among peers, sealed so they cannot read it
  • Organizations: roles, members, resources, endpoints and templates; the Orgs menu
  • Pipes: pipe any data through code spaces, filter it, save it on the way
  • Pipelines: design note for saved pipelines that end in a model table
  • Share: share anything to a project, a journal, a code space or your exchanges
  • Reviews: review links, comments, suggestions, highlights, votes, merges and revisions
  • Deploying a relay: a public relay node on a droplet: DNS, systemd, firewall, ACME
  • Org hosting: HTTPS sites with HTML, JSON and gRPC, signed member requests, Let's Encrypt
  • Notifications: the header bell, mnnn notify, rule-set notify and broadcast actions, node broadcasts
  • Live collaboration and peers: messages, live editing with cursors, the peers view, running a peer's executables
  • MCP: Muninn as an MCP server (stdio, HTTP, HTTPS with Let's Encrypt; named clients with roles), external MCP servers for rule sets
  • MCP behind nginx: the MCP HTTP server behind nginx with a certbot certificate
  • Org site templates: edit, preview and build an org site's look; site announcements

Quick start

export MUNINN_HOME=/tmp/mnnn-demo          # never touches ~/.muninn
mnnn keys init                             # write down the words and shards
mnnn ingest csv --path ~/Projects/kommandosaldat/raw/data --source binance -y
mnnn export --format parquet --out /tmp/btc.parquet --symbol BTC/USDT
mnnn search save "btc 5m" --symbol BTC/USDT --period 5m
mnnn project create Research && mnnn project add Research --search "btc 5m"
mnnn tui
